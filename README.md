# Lendsqr Frontend Test

A responsive admin dashboard with a login page built with Next.js, TypeScript, and SCSS.

## Technologies Used

- **Next.js** – React framework for server-side rendering and static site generation
- **TypeScript** – Typed superset of JavaScript for better developer experience
- **SCSS** – CSS preprocessor for modular and maintainable styles

## Getting Started

Follow these steps to clone and run the project locally:

### Prerequisites

- Node.js (v14 or higher recommended)
- npm

### Clone the repository

```bash
git clone https://github.com/victoribironke/lendsqr-fe-test.git
cd lendsqr-fe-test
```

### Install dependencies

Using npm:

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

> **Note:** This project does not require any environment variables to run locally.
